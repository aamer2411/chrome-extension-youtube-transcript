# YouTube Transcript

A lightweight Chrome extension that adds a download button under any YouTube video. One click saves the video's transcript as a plain text file named after the video.

## Features

- **One-click download:** a button sits next to the Subscribe button under the video.
- **Clean output:** one caption line per line of text, no timestamps, no markup.
- **Sensible file name:** saved as `<video title>.txt`, with only the characters Windows forbids replaced.
- **Best track first:** human-written English captions, then auto-generated English, then whatever language the video has.
- **Works across navigation:** YouTube swaps videos without reloading the page; the button follows along.
- **Private by design:** no extra permissions, no external servers, no tracking. Everything runs in your browser on youtube.com.

## Installation

### From the release zip

1. Download the latest `youtube-transcript-v*.zip` from the [Releases](../../releases) page and unzip it.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select the unzipped folder.

### From source

```bash
git clone https://github.com/aamer2411/chrome-extension-youtube-transcript.git
```

Then follow steps 2 to 4 above, selecting the cloned folder.

## Usage

1. Open any YouTube video.
2. Click the download icon next to the Subscribe button.
3. The transcript is saved to your Downloads folder.

If an ad is playing, wait for it to finish and click again.

---

## How It Works

YouTube only serves caption files with a short-lived token generated by its own player. The extension:

1. Reads the list of caption tracks from the video's watch page data.
2. Picks the best track (see Features).
3. Briefly toggles the player's subtitles so the player requests captions, then reads the token from that request.
4. Fetches the captions in JSON format, flattens them to plain text lines, and saves the file.

The subtitle setting is restored to how you had it.

## Permissions

| Item | Value | Why |
|---|---|---|
| Permissions | None | Not needed |
| Runs on | `https://www.youtube.com/*` | Adds the button to video pages |
| Network | youtube.com only | Fetches the caption track for the open video |

## Limitations

- Videos without captions (human or auto-generated) have nothing to download.
- YouTube changes its page structure from time to time; if the button stops appearing, an update may be needed.
